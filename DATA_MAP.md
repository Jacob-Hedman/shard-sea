## Where each kind is stored

Flexible core: **`entity`** (kind, slug, name, `tier`, `summary`, `effects`, `attrs_json` = every parsed field, `raw_md` = verbatim). Promoted typed tables:

| Kind | Typed table |
|---|---|
| feat | `feat` |
| discipline | `discipline` |
| weapon | `weapon` |
| armor / shield | `armor` |
| archetype | `archetype` |
| condition | `condition` |
| action | `game_action` |
| rune / material | *(entity + attrs_json only)* |

Prose pages live in **`page`** (`body_md` rendered, `raw_md` verbatim). Version history for the changelog lives in **`snapshot`** + **`change_entry`**.
